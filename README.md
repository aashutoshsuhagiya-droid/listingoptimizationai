# Listing Optimization AI

A production-ready, responsive SaaS marketing page built with semantic HTML, CSS, and vanilla JavaScript.

## Run locally

Open `index.html` directly, or serve the folder with any static server:

```powershell
npx serve .
```

No build step or runtime dependencies are required. The project can be deployed directly to Vercel, Netlify, GitHub Pages, or any static host.

## Included

- Complete 20-part marketing experience from the supplied brief
- Responsive desktop, tablet, and mobile layouts
- Variant studio tabs, monthly/yearly pricing, testimonial carousel, video interaction, and mobile menu
- Custom local logo and 50-star US marketplace flag SVG assets
- Six linked customer video testimonials with YouTube thumbnail previews
- Fifteen-marketplace selector and a 15-question accessible FAQ accordion
- Accessible landmarks, labels, reduced-motion handling, and semantic content

The product galleries currently use lightweight art-directed mockups. They are structured so final campaign imagery can replace them as soon as approved source assets are available.
