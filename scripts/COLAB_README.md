# Generate Images with Google Colab + Stable Diffusion

## What This Gives You
- Free GPU via Google Colab free tier
- Stable Diffusion WebUI (Automatic1111)
- Public Gradio interface you can open in your browser
- Persistent storage via Google Drive
- No local GPU required

## Files
- `generate-images-colab.ipynb` — ready-to-run Colab notebook

## How to Use
1. Go to https://colab.research.google.com
2. Upload `scripts/generate-images-colab.ipynb` or open it from Google Drive
3. Run the cells in order
4. Open the Gradio URL and generate images
5. Download generated images into the local `images/` folders

## Requirements
- Google account
- Stable internet connection
- Optional: Google Drive for persistent storage

## Notes
- Free tier sessions last 4-12 hours
- If the session times out, rerun the notebook
- For text accuracy, add text overlays in Canva/Photoshop after generation
